# Draw Daifugo PoC

要件定義に基づくドロー大富豪の試作版です。次の2つの遊び方に対応しています。

| 遊び方 | 仕組み |
|---|---|
| **この端末で遊ぶ**（ローカル対戦） | 1台の端末を回して遊びます。ゲームはブラウザ内だけで処理し、サーバーへは送信しません。 |
| **オンライン対戦** | 募集人数を決めてルームを作ると、4桁のルーム番号で募集が始まります。ほかの人は募集一覧・ルーム番号・招待リンクのいずれかから参加し、人数がそろうと自動で開始します。カード配布・合法手・勝敗はサーバーで判定し、各プレイヤーには自分の手札だけを送ります。 |

ゲームのルール判定は共通のTypeScriptエンジン（`src/game/engine.ts`）で行い、オンライン対戦ではこれをサーバー上で実行します。

## 構成

```text
src/game/        ゲームエンジン（UIに依存しない）
src/online/      オンライン対戦の通信の型（サーバーと共有）と接続処理
src/components/  画面
server/          Node.jsサーバー（静的ファイル配信 + WebSocket /ws + /healthz）
tests/           エンジンとルーム管理のテスト
```

## 起動方法

### Docker

リポジトリルートで実行します。

```powershell
docker build -t draw-daifugo-poc .\02.poc
docker run --rm -p 8090:8090 draw-daifugo-poc
```

ブラウザで `http://localhost:8090` を開きます。社内サーバーへの配置・更新・ロールバックの手順は [デプロイ手順書](../01.docs/03.デプロイ手順.md) を参照してください。

このPoCには認証・アクセス制御がありません。社内ネットワークへ公開する際は、検証用ネットワークに限定するか、前段でアクセス制御を設定してください。

### 開発モード

画面（Vite）とサーバーを別々のターミナルで起動します。Viteは `/ws` をサーバー（:8090）へ転送します。

```powershell
Set-Location .\02.poc
npm ci
npm run dev:server   # ターミナル1：サーバー（:8090）
npm run dev          # ターミナル2：画面（http://localhost:5173）
```

オンライン対戦を1台で試す場合は、ブラウザのタブを2つ開いてそれぞれ参加します（参加情報はタブごとに保持されます）。

## オンライン対戦の仕様（PoC）

- ホスト（作成者）が募集人数（2～5人）・手札枚数・ジョーカー枚数を決めてルームを作ります。ルーム番号は4桁の数字です。
- 公開ルームはトップ画面の「募集中のルーム」にリアルタイムで表示され、残り枠の少ない順に並びます。満員・開始済みのルームは一覧から消えます。「募集一覧に公開」をオフにすると、ルーム番号を知っている人だけが参加できます。
- 募集人数がそろい全員が接続中になると、5秒のカウントダウン後に自動で開始します。カウントダウン中に誰かが退出・切断すると取り消されます。ホストは人数がそろう前でも、2人以上いれば「待たずに今の人数で始める」で開始できます。
- ゲーム中・満員のルームには参加できません。
- ブラウザを再読み込みしたり通信が切れたりしても、同じタブから自動で同じ席に戻れます。
- 切断したプレイヤーの手番は45秒後に自動でパスします（7渡し・10捨ては手札の先頭から自動選択）。途中で退出した場合は即座に自動進行になります。
- ルームはサーバーのメモリ上にのみ保持します。サーバーを再起動すると進行中のルームは消えます。全員が切断したルームは15分後に削除します。
- 手番以外の操作、手札にないカード、不正な形式のメッセージはサーバーで拒否します。

## ルールの範囲・仮ルール

- 2～5人、手札5～7枚、ジョーカー0～2枚です。
- 数字の組、3枚以上の同一スート階段、ジョーカー単体、革命、11バック、5スキップ、7渡し、8切り、10捨て、スペード3のジョーカー返し、縛り、ドローおよび場流しを実装しています。
- 縛りは連続するプレイで共通するスートがある場合に成立する仮ルールです。成立後は場が流れるまで維持し、縛られたスートをすべて含む必要があります（不足分はジョーカーで補えます）。
- ジョーカーは単体では最強、組・階段では不足カードの代用として扱います。代用スート・数字を利用者が個別選択するUIは未実装です。
- 革命中と11バック中の比較は排他的論理和で反転します。場が流れても革命は維持し、11バックは解除します。
- 5の枚数分スキップ、7・10の枚数分のカード選択、8切りで同じプレイヤーが次の場を開始する動作を仮採用しています。
- 1回のプレイで複数の効果が成立した場合は「7渡し → 10捨て → 8切り → 5スキップ」の順に処理します（8切り成立時はスキップしません）。
- 特殊効果を伴うカードで上がることは禁止します。7渡し・10捨ての結果として手札を0枚にすることも禁止し、手札が足りない場合は最低1枚残るよう枚数を減らします（0枚になる場合は効果を省略）。
- ローカル対戦では、手番が変わるたびに受け渡し画面で手札を隠します（設定でオフにできます）。
- 全員パスで場を流し、最後に役を出したプレイヤーが次の場を開始します。勝敗は最後の1人まで続けて順位を確定します。
- 使用カード・捨て札はターン終了時に山札へ戻してシャッフルします。実際のルール確認後に変更してください。

これらはPoCを動かすための暫定仕様であり、未確定事項を確定するものではありません。CPU対戦、認証、戦績の保存、ルームの永続化は対象外です。
